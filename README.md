## Architecture taste

I like systems with layers.

```txt
input
  ↓
context
  ↓
reasoning / rules / retrieval
  ↓
decision
  ↓
action
  ↓
feedback loop
```

The boring part is usually where the product becomes real:

```txt

data model
latency
cost
roles
permissions
deployment
monitoring
edge cases
```

That is where I like building.
